## Findings corrected during verification

- Hub instances have their own DI scope: sandbox binding now comes from the authenticated HTTP connection scope.
- macOS does not support the EphemeralKeySet import flag: only that platform uses the supported external-key import mode; Linux uses ephemeral import of the stable external certificate, never certificate generation.
- Explicit initializer transaction rebinding now restores an owned Identity connection, so repeat invocation in the same scope is safe.
- Demo logout revokes its exact lease, while reuse rotates its stamp. This closes a late-logout race with newly reserved identities. Normal logout still invalidates all its account sessions.
- Disabled pool accounts are excluded from availability/allocation. Runtime grants exclude identity creation/role mutation and normal-mode history.
- Local container-group and tmpfs configuration were corrected and verified in the actual image/Compose run.
